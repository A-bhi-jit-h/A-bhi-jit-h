A computer vision-based application that recognizes Malayalam sign language gestures and converts them into Malayalam text.

**Tech:** Python, OpenCV, MediaPipe, Random Forest, Flask, HTML, CSS, JavaScript.

### 2. AI-Based Budget Allocation System

An intelligent budget prediction system designed to estimate ward-level financial requirements using historical expenditure, socio-economic indicators, and citizen feedback.

**Tech:** Python, XGBoost, GNN, BERT, spaCy, Flask, MySQL.

### 3. Cephalometric Landmark Detection

A deep learning-based system for detecting anatomical landmarks in dental X-ray images using heatmap regression and U-Net architecture.

**Tech:** Python, PyTorch, U-Net, NumPy, Deep Learning.

**Tech:** Python, Flask, spaCy, BERT, MySQL, REST APIs.
